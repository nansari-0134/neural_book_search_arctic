# Data Directory Schema & Documentation

This directory houses the catalog metadata and training datasets for the **ArcticDense** neural book retrieval system.

> [!NOTE]
> Large raw data files (`*.jsonl`, `*.sqlite3`) are excluded from Git version control via `.gitignore` to comply with repository hygiene and GitHub's 100MB file limit.

---

## 🗄️ Database Schema: `books_metadata.sqlite3`

Contains **64,552 curated books** extracted from the UCSD Goodreads dataset.

| Column | Type | Description |
| :--- | :--- | :--- |
| `book_id` | `TEXT PRIMARY KEY` | Unique Goodreads book identifier |
| `title` | `TEXT` | Canonical book title (including series/subtitles) |
| `authors` | `TEXT` | Author list JSON |
| `description` | `TEXT` | Full book synopsis / blurb |
| `popular_shelves` | `TEXT` | JSON list of community tags & genre shelves |

---

## 📄 Dataset Partitions

The dataset splits follow a strict work-cluster division to prevent semantic leakage between training and evaluation:

1. **`train.jsonl`** *(258,250 pairs)*:
   - Base training corpus containing up to 5 diverse synthetic queries per book generated by Qwen3-8B.
   - Format: `{"query": "...", "positive_id": "...", "positive_text": "..."}`
2. **`val.jsonl`** *(32,340 queries)*:
   - Held-out validation split evaluated against the full 64,552 catalog books.
3. **`test.jsonl`** *(32,170 queries)*:
   - Final blind test benchmark evaluated against the full 64,552 catalog books.
4. **`train_arctic_v2.jsonl`** *(199,808 pairs)*:
   - Hard-negative training dataset mined directly from the retriever's confusion zone (Ranks 2–35) with the 8-layer false-negative defense shield. Contains Top-5 mined hard negatives per query.
5. **`train_arctic_v3.jsonl`** *(179,319 pairs)*:
   - Progressive refinement dataset containing 3 fresh hard negatives from the updated decision boundary + 2 retained hard negatives.
